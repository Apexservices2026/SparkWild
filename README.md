# Sparkwild (working title)

A cozy survival game: gather, craft, build and survive moonlit nights. Plays in the browser on phone, tablet and computer.

**Play:** https://apexservices2026.github.io/SparkWild/
On iPhone: open it in Safari, tap Share, then **Add to Home Screen**.

This repo holds the published game only. The source and project notes live in Apexservices2026/claude-brain-dump (`projects/survival-game/`); update this repo with `projects/survival-game/game/tools/build-web.sh` and copy `projects/survival-game/web/` here.

Uses Three.js (MIT licence, see `vendor/THREE-LICENSE.txt`).
